# Design 1 — Navy + Blue Theme

**Cohesive blueish theme** using light, mid, and navy blues.

## Color Palette

| Role | Color |
|------|-------|
| Navy (dark) | `#0A1628`, `#0F172A`, `#1E3A5F` |
| Blue (mid) | `#2563EB`, `#3B82F6`, `#60A5FA` |
| Light backgrounds | `#EFF6FF`, `#DBEAFE`, `#BFDBFE` |

All sections use **variations of the same blue family** — navy for nav/footer/dark sections, sky blues for backgrounds, royal blue for CTAs and accents.
