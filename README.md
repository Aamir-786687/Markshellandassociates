# Markshel Land & Associates

Premium intellectual property law firm website concepts and production React application.

## Production App (React 19)

```bash
cd website
npm install
npm run dev
```

Open `http://localhost:5173` — full React app with animations, 10 service pages, AI illustrations in `public/Images/`.

## Static Design Concepts (JSX React Apps)

Each folder is a **Vite + React (.jsx)** app using generated images from `public/Images/`.

| Folder | Style | Run |
|--------|-------|-----|
| `Design1/` | **Navy + Blue** — light, mid, and dark blues (cohesive theme) | `cd Design1 && npm run dev` |
| `Design2/` | **Dark premium** — charcoal/black + gold/copper (not white & blue) | `cd Design2 && npm run dev` |
| `Design3/` | **Creative teal** — cream + deep teal, bento grid, glass nav | `cd Design3 && npm run dev` |

All use `.jsx` only (no TypeScript). All 8 pages + 10 service detail routes.
